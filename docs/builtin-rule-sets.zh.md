# 内置规则集预设（0.1.39）

入口：**规则 → 规则集 → 内置规则集**。

预设库包含 17 项，可按本地网络、国内外、常用服务筛选或搜索。点击对应预设的“新增”即可添加到当前规则集列表。添加过的预设显示“已添加”，不重复导入；后续仍可编辑、更新、停用和删除。

## 提供的内容

| 类别 | 预设 |
|---|---|
| 随软件提供，无需联网 | 本地域名、局域网地址 |
| 国内外 | 国内域名、国内 IP、国外域名 |
| 常用服务 | 广告域名、AI 服务、YouTube、Google、Telegram 域名、Telegram IP、GitHub、Microsoft、Apple、哔哩哔哩、Netflix、Steam |

本地域名包含 `localhost` 及 `localhost/local/lan/home.arpa` 子域名；局域网地址包含 IPv4/IPv6 私有、回环和链路本地网段。它们是随前端打包的小型本地文本列表。

其余 15 项内置的是来源定义，第一次添加时需要下载。来源使用 [MetaCubeX 官方文档](https://github.com/MetaCubeX/meta-rules-dat/blob/master/README.md) 所述的 `meta/geo/geosite` 和 `meta/geo/geoip` MRS 规则，提供 CDN 与 GitHub 两种下载来源选择。默认更新周期为 24 小时，下载出站可选直连、节点、策略组或链式代理。这里的来源和下载出站只用于新添加的在线预设。

在线内容下载、解析后缓存到本机并记录摘要，沿用现有资源导入和热更新流程。失败时不添加半成品；并发修改携带修订，避免覆盖其他编辑。添加成功或失败后回读实际状态，避免重试时重复添加。

## 如何使用

规则集定义的是匹配范围。添加后，在**规则 → 路由规则**或 **DNS → 解析策略**中选择对应规则集，再设置出站、解析池或地址模式。

例如：国内域名可分配到国内解析池，国外域名可分配到国外解析池；广告域名需要另外设置阻断动作。IP 规则只可用于适用 IP 条件的阶段，不能用于查询前尚无目标 IP 的 DNS 解析策略或 Fake-IP 域名投影。

新增预设不会自动插入路由、DNS 策略或切换当前出站。已有规则优先级与全局/直连模式的行为继续沿用当前配置。
