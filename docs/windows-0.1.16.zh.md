# Windows x64 0.1.16：链接自动识别与规则管理

## 添加节点 / 订阅

统一粘贴输入框根据链接自动识别类型，不再需要手动切换：HTTP / HTTPS 地址作为订阅，支持的节点分享协议作为节点。识别在本地完成，点击添加前不请求订阅服务器。

单条链接自动建议一个可修改的名称；节点名称按 UTF-8 的 64 字节限制截断并处理重名。VMess 链接优先读取名称字段，其他节点优先读取链接备注。多条节点链接每行一条，沿用最多 200 条的批量预览、错误提示与有效节点添加逻辑。混合节点和订阅、一次粘贴多个订阅时保留内容并提示分开添加。已有订阅与节点的修改入口继续保留。

## DNS 新建规则

原默认配置只有 DNS 上游，没有请求、响应规则块，界面无法找到新建规则的插入位置。现在缺少 DNS、routing 或 request / response 块时会在保存时补齐对应层级；同时识别原生直接嵌套的 DNS 列表。存在显式兜底规则时继续在兜底前插入普通规则。

共享引擎返回显式 DNS 兜底规则的源位置，便于准确编辑与定位；隐式兜底规则仍显示为无源位置，新建或修改时生成所需文本。多配置源沿用配置代次、源版本和完整配置校验。

## 重置为默认

路由规则、DNS 请求规则、DNS 响应规则分别提供“重置为默认”。点击后先展示默认内容和影响范围，确认后才写入：

- 路由：恢复出厂的 localhost、127.0.0.0/8 直连规则，以及 direct 兜底；清除当前路由列表及模式覆盖。
- DNS 请求：清除请求列表的自定义规则和显式兜底，恢复使用已配置的首个上游；无上游时不会自行新增。
- DNS 响应：清除响应列表的自定义规则和显式兜底，恢复 accept。

每次操作只处理所选规则列表。保留其他列表、订阅、节点、策略组与 DNS 上游；不会重置整份用户配置。

## 拖拽排序

每个列表增加“拖拽排序”，在弹窗中使用手柄或上下按钮调整，点击“保存顺序”提交。规则按从上到下的顺序匹配；兜底规则与模式规则固定，普通规则不足两条时不提供排序。

保存时将当前列表集中写入主配置，其他规则列表保持原有内容。保留规则行内注释，独立注释集中保存在该列表顶部。若无法安全定位列表、含有额外嵌套配置块，或配置已变更，会拒绝排序并保留草稿。

后端新增默认预览、列表重置与顺序提交接口；保存前检查配置代次、主配置及 include 源快照，构建候选配置并核对排序结果、兜底以及其他列表和节点、组、上游是否保持一致。多源在同一配置锁内校验与写入，失败时尝试恢复已写文件，成功后发布一次新代次。

## 构建范围

执行 TypeScript 类型编译、Rust 编译与 Windows x64 安装包构建。未运行测试或启动客户端、内核、服务；未修改当前用户配置、代理或 TUN，未安装或替换正在使用的软件。本轮没有进行运行验收。正式发布与 ARM64 延后，macOS / Linux 本轮不构建。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.16_x64-setup.exe`。构建日志、SHA256 和构建记录位于 `app/src-tauri/target/`。
