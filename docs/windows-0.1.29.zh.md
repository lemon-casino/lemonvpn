# Windows 0.1.29：跟随已应用出站、删除节点和出站

活动中的出站卡片从后端已接受的主配置读取全局出站，自动显示对应的策略组或链式代理，标题与内容使用同一来源。移除桌面卡片的独立组选择器，忽略历史卡片组偏好；尚未点击“应用”的模式／出站草稿不改变卡片。规则或直连模式显示对应说明，不自动选一个无关的组。组内节点切换和链式代理的现有实时效果保持可用。

订阅页的节点操作菜单和批量操作支持删除受管理的订阅节点。订阅节点的本地删除指纹保存在订阅数据中，刷新或重启后继续生效；保留原始位置为重名节点预留名称，避免删除一个节点后另一个节点悄悄占用其名称。手动节点仍从手动来源中移除。订阅节点计数仅包含未删除的节点。

节点删除持有配置发布锁，并在订阅数据锁内校验候选配置：直接被规则、默认成员或链路端点引用，或删除会使现有链路失效时拒绝保存并返回具体原因。验证与保存失败均恢复订阅数据；成功后发布新配置、清理该节点的固定选择并热更新。前端保留后端的真实拒绝原因，避免覆盖成笼统的配置冲突。

出站页的策略组与链式代理菜单均新增“删除”，经确认后从实际声明源移除并热更新，保留节点和订阅。删除前检查全部完整配置源中的路由、fallback、组引用和链路引用，列出阻塞引用；正在使用的全局出站须先更换目标并点击“应用”，被规则或其他链路使用的组须先解除引用。写入使用原有完整校验与版本检查，不自动改成直连。无效 fallback 出站现在作为校验错误拒绝写入，删除后的组固定选择也会清理。

仅进行前端类型、相关 ESLint、格式、Rust workspace 编译与构建产物检查，并构建 Windows x64 安装包。没有运行测试、实际删除任何用户节点／组、刷新订阅、访问运行中的 API、网络探测、启动或替换当前软件／服务，未修改当前用户配置、系统代理或 TUN。正式发布、ARM64 及其他系统构建继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.29_x64-setup.exe`。
