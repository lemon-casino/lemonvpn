# Windows 0.1.30：替换引用并删除出站

策略组和链式代理的删除弹框显示引用类型、文件、行号与所属组，有引用时提供“引用替换为”和“替换并删除”。一次选择统一处理普通路由规则、全局出站、fallback、其他组的回退、链路前置／落地和组筛选引用；无引用时仍可直接删除。不预选替换目标，不修改无关节点、订阅、域名、注释或 DNS 配置。

替换项按策略组、链式代理、节点与内置出站分组。排除待删组及依赖它的出站，避免循环；链路端点不提供 direct／block，组筛选只提供具有成员列表的策略组。支持中文、带空格名称和组筛选中的多个参数、否定与竖线列表。组筛选按依赖顺序解析，允许选择写在其他文件或后面的策略组，同时拒绝循环和不存在的引用。

前端基于完整配置快照生成精确的文本修改，后端在同一配置发布锁内检查配置代次、每个源的旧摘要和实际磁盘内容，完整验证新配置，核对路由条件与顺序、fallback、其他组的策略及引用，以及节点与 DNS 内容。全部源保存成功后仅发布一次新配置并热更新，清理删除组和失效成员的固定选择。校验失败不会写入；保存中失败按旧内容恢复已写文件，并保留检测到的外部修改。

成功后主动刷新配置、出站、活动卡片和链路预览，清除旧的出站模式草稿。替换成已有节点或内置出站时，全局出站控件仍能显示已应用目标。旧后端不支持批量引用替换时不会降级为逐个保存，仅保留无引用组的原删除能力。

按用户要求只修改代码，进行类型、相关 ESLint、格式、Rust workspace 编译、构建与产物检查。没有运行测试、访问当前软件 API、删除用户组、替换用户规则、刷新订阅、修改实际配置、系统代理或 TUN，也没有启动、安装或重启软件／服务。正式发布、ARM64 及其他系统构建继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.30_x64-setup.exe`。
