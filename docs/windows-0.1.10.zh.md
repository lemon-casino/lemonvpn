# Windows x64 0.1.10

## TCP / UDP 范围

- 策略组中的“两者 / TCP / UDP”用于选择后续成员操作的协议范围。摘要随范围显示当前 TCP、UDP 或两个协议各自使用的节点，界面同时说明该操作用于新连接。
- TCP、UDP 的健康状态、延迟、可用成员统计分别读取；UDP 没有观测时显示未观测，不再沿用 TCP 的结果。嵌套组的状态也按所选网络解析。
- 固定、解除固定及恢复自动选择只作用于当前范围。修复后端忽略 DELETE 请求的 network 参数、总是一起清除两个协议选择的问题。
- 选择操作保持忙碌状态直到节点和组状态读回，防止快速点击读到上一次选中状态。

## 再次点击解除固定

- 自动策略组中点击节点可手动固定，包括自动策略当前正在使用的节点。
- 再次点击当前范围内已固定的同一节点，解除固定并恢复自动选择。
- 自动使用的当前节点标记与固定选中样式区分；解除固定后，即使自动策略仍选择同一节点，也会去掉固定选中样式。
- 普通手动选择组继续直接选择成员。

## UDP 观测

- 兼容内核可用时提供 DNS UDP / DNS TCP+UDP 探测，经该节点的实际 UDP 中继向配置的 DNS 上游发出查询并校验响应；UDP 探测不回退为 TCP。
- 按 TCP 或 UDP 范围选择可用的探测方式；不支持当前范围时禁用操作，不会静默探测另一种协议。
- 观测按节点、协议、地址族和测量类型分别记录，探测结果正确标注传输协议、测量方式及前后选中成员。
- 自动策略的 UDP 健康统计独立于 TCP，采用 UDP DNS 观测和实际 UDP 会话反馈。DNS 上游单独失败会降低候选排名，不会因此直接认定整个 UDP 中继不可用。
