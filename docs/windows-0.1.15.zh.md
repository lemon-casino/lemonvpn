# Windows x64 0.1.15：批量所属组与统一添加入口

## 批量管理所属组

在订阅节点列表中勾选节点，工具栏会出现“批量管理所属组（数量）”。支持搜索组、查看所选节点，以及以下三种操作：

- 加入组：将指定组加入每个所选节点，保留它们各自原有的其他组。
- 移出组：从每个所选节点移出指定组，保留其他组；本来不在这些组中的节点跳过。提供移出所有可修改组的快捷选择。
- 更换组：把每个所选节点可修改的所属组统一更换为指定组，逐节点保留不可修改的成员关系。必须选择目标组，避免把空选择当成整批清空。

组旁显示所选节点已有多少个在该组，区分不同节点的原有状态。保存前显示实际会修改的节点数。勾选范围随搜索、来源和筛选变化而清理，打开弹窗后固定本次所选节点与原所属组快照。

后端新增 `PUT /api/v1/nodes/groups`，一次最多 256 个节点。单节点与批量操作共用配置代次、原所属组、节点存在性和配置源版本检查，在一个配置锁内统一生成、校验并提交。任一所选节点失效或变更时整批拒绝；写入失败会尝试恢复已写文件，不逐个发起互相独立的保存。成功后一次发布新代次。

复用并扩展单节点的精确排除、嵌套组重算、默认成员及固定选择清理；验证未选节点的成员关系保持一致。批量排除条件合并为名称列表，避免为每个节点反复解析、构建和写入配置。单节点原入口继续保留。

## 添加节点 / 订阅

原“添加订阅”和节点工具栏的“粘贴节点链接”合并为一个“添加节点 / 订阅”按钮，空列表也使用此入口。在同一弹窗切换：

- 订阅链接：添加订阅地址、名称及更新选项。
- 节点链接：添加单条节点链接，或粘贴多条链接后预览、批量添加，保留原协议和 XHTTP 选项。

切换类型时分别保留尚未提交的输入，避免丢失另一类型的草稿；保存期间禁用类型切换。已有订阅和节点的修改、删除入口不受此合并影响。

## 构建范围

执行 TypeScript 类型编译、Rust 编译及 Windows x64 安装包构建，未运行测试或启动客户端、内核和服务，没有切换代理、TUN 或更新当前软件。本轮未进行运行验收。正式发布及 ARM64 延后，macOS / Linux 本轮不构建。
