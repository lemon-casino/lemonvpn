# Windows x64 0.1.5

仅调整桌面导航和小工具布局，沿用 0.1.4 的 TUN 服务通信实现。本轮未启动客户端或服务、未切换代理/网卡、未执行测试；只做 TypeScript 编译和 Windows x64 构建。正式发布与 ARM64 继续延后。

- “常用”和“网络与工具”菜单采用每行两个入口，原有页面均保留，设置仍位于底部。
- 展开的小工具停靠区域使用固定默认高度，内部内容独立滚动；用户拖动设置的高度仍保留。模式切换与数据刷新不再决定整个停靠区的高度。
- 规则、直连、全局共用固定的选择、全局出站与应用按钮位置，全局出站行在其他模式下保留位置，原有确认与应用逻辑保留。
- 侧栏图表悬停信息通过 portal 显示在侧栏外侧，按视口边界定位，避免遮住或被模式控件覆盖。滚动、调整窗口、按 Escape 或点击其他控件时关闭提示；其他页面图表保留原有提示方式。
- 图表与网格限制在侧栏宽度内，图表与其他小工具增加间距。展开、收起与取消嵌入操作仍在三个点菜单中。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.5_x64-setup.exe`。构建不自动安装或替换正在使用的软件。
