# Windows x64 0.1.6

- 修复桌面侧栏小工具右侧的速率、内存单位与模式控件被裁切：覆盖共享停靠布局的负边距，内容宽度以卡片实际可用空间为准，且不受小工具样式延迟加载的顺序影响。
- 桌面活动小工具移除“应用”按钮和按钮预留行。选择规则、直连、全局或更改全局出站后立即提交配置，沿用原有校验与生效流程；请求进行中禁用重复操作，失败后恢复实际配置的选中状态并提示原因。
- 全局模式未配置可用出站时保留选择和提示；选择出站后直接提交。模式与出站直接通过点击事件提交，不因打开小工具或加载保存的草稿而自动修改配置。
- 模式切换继续保留固定的全局出站行，小工具停靠高度不随模式变化。
- 中文导航和对应页面标题“系统状态”改为“状态”。

本轮只做 TypeScript 编译与 Windows x64 构建，未运行测试、启动客户端、安装更新、重启服务或切换使用中的代理与网卡。正式发布和 ARM64 继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.6_x64-setup.exe`。
