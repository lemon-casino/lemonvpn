# Windows 0.1.28：活动出站卡片与流动链路

活动里的策略组、链式代理卡片用于查看与切换成员。切换卡片展示的组／链路只更新卡片偏好，不修改出站模式或全局出站；实际出站仍由“出站模式”的选择和“应用”控制。

普通策略组的组名、协议、成员选择器改为紧凑排列，移除把节点选择器推到最右侧的布局。链式代理改为本机、前置、落地、目标的单行布局，前置／落地不再上下堆叠。重复节点名、流量统计和说明从活动卡片移除，详细信息留在出站的“链路预览”；移除活动里的“管理链式代理”链接。

链式代理两端引用策略组时，可直接在节点卡片中选择组内成员，按当前 TCP 或 UDP 热更新；自动策略可固定节点，再选已固定节点恢复自动选择。直接引用节点的一端保持只读。选择调用现有组选择接口，仅关闭受该组及协议影响的旧链路连接；完成后主动刷新两种协议的链路快照、组和已打开的链路预览，避免等候事件刷新间隔。不会随卡片组选择而启用该出站。

活动和链路预览使用同一套流动效果。上传、下载以相反方向沿虚线连续流动，采样期间的正字节增量驱动播放，跨采样保持动画连续，不再每秒闪播一个光点。没有流量、数据过期、页面不可见或获取失败时停止；减少动态效果设置下只显示静态链路。活动只展示当前选择对应的实际连接，预览可展示实际仍在使用的其他路径并明确区分，避免把旧连接流量画到新节点上。

仅执行类型、相关 ESLint、格式与构建产物检查，以及 Windows x64 安装包构建。不运行测试、网络探测或实际流量验证，不启动、安装、替换或重启当前软件／服务，不修改当前用户配置、代理或 TUN。正式发布、ARM64 及其他系统构建继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.28_x64-setup.exe`。
