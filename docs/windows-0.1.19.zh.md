# Windows x64 0.1.19：出站模式的应用按钮紧邻模式选择

0.1.18 在模式选择与“应用”之间保留全局出站的占位，虽然维持了模式切换时的位置，却把按钮隔得过远。

本轮将模式选择与“应用”放入同一个紧凑控件组，把全局出站及其占位移到该组后面。规则、直连、全局三种模式共用相同布局；全局出站仍只在全局模式下可见与可操作，隐藏时保留尺寸。“应用”不再隔着空占位，也不使用自动外边距或拉伸来推向卡片右侧。窄窗口下控件组可整体换行，保留相邻关系。

侧栏活动小工具继续沿用 0.1.18 的固定行高与直接切换交互，本轮未调整侧栏。

执行修改文件的静态检查、TypeScript 类型编译和 Windows x64 安装包构建；未运行测试、启动客户端或内核、修改当前配置，也未替换正在使用的软件或服务。本轮没有运行验收。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.19_x64-setup.exe`。正式发布、Windows ARM64 和其他平台构建继续延后。
