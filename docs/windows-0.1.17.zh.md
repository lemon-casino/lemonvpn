# Windows x64 0.1.17：列表拖拽与桌面配置页面

## 规则列表直接排序

移除“拖拽排序”按钮与排序弹窗。路由、DNS 请求、DNS 响应的原列表行增加拖拽手柄，鼠标或键盘拖动后自动提交，不需要再打开一个窗口。固定的模式规则、无法修改的规则与兜底规则保留原位置。

提交时显示待保存的顺序并暂时禁用再次排序；保存失败恢复列表并提示原因。拖拽起始配置代次与提交代次必须一致，后端仍检查完整 ID 排列、源快照和候选配置。重置默认规则继续保留独立的确认与默认内容预览。

0.1.16 在保存时把 React Aria 的拖拽 Hooks 从组件中临时移除，会改变库内部 Hooks 的调用顺序，是 React #311 的一个触发点。本轮保持拖拽和放置 Hooks 持续挂载，只通过禁用状态锁定保存期间的交互；原列表无拖拽能力和有拖拽能力之间的结构切换也由独立组件实例承担。

## 配置模块与 DNS 页面

桌面端模块概览改为读取引擎当前的订阅、节点、策略组、路由与 DNS 规则资源，并提供直接管理、新增和追踪入口。由界面动态管理的订阅、节点不再因未写在主配置中而被概括为“未设置”。桌面与引擎设置指向实际设置页，日志与记录也有对应入口，避免打开当前适配器不提供的 global 表单。

DNS 页新增“上游配置”标签，支持新增上游、修改服务器地址、删除未被规则引用的上游。修改保留原上游名称，至少保留一个上游。支持当前共享引擎实际接受的 UDP、TCP、TCP+UDP 地址及端口，未加入不会生效的其他协议选项。

保存沿用配置源摘要与代次校验，以及完整候选配置验证；保留 DNS 请求和响应规则、其他上游及注释。模块概览与搜索同时识别直接嵌套和 routing 内嵌的 DNS 规则计数。

## 活动页出站控制

出站模式和全局出站合成一张卡片，仅在选中“全局”模式时展示全局出站选择。模式与目标共用一个“应用”按钮，一次提交同一份配置修改。桌面端不再增加第二次模式确认。原活动布局中的独立全局卡片合并到模式卡片，图库也不再提供重复的独立全局卡片；保留其他布局设置。侧栏活动小工具继续沿用直接切换模式的交互。

## 顶部与提示框

移除顶部“报告问题”按钮。提示框在窗口失焦、调整大小、滚动、点击或页面隐藏时关闭；锚点不可见或失效时关闭，尚未完成定位的提示框不绘制，减少漂到左上角的孤立文字。

## 构建与验证范围

执行修改文件的静态检查、TypeScript 类型编译与 Windows x64 安装包构建。遵照本机使用约束，没有运行测试、启动客户端或内核、修改当前用户配置，也没有更新正在运行的软件或服务。本轮修改尚未进行运行验收。正式发布与 Windows ARM64 继续延后，macOS / Linux 本轮不构建。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.17_x64-setup.exe`。
