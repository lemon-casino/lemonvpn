# 大规则集索引与配色调整（0.1.40）

## 正则索引超限

报错 `Compiled regex exceeds size limit of 16777216 bytes` 来自规则集编译，而不是规则集未下载。旧实现将 domain 类型中的大量 `.example.com` 子域名条目展开成正则，再合并进单个 16 MiB 正则索引；普通的大型域名列表也会触发此限制。

固定内核的 [DomainSet 实现](https://github.com/MetaCubeX/mihomo/blob/v1.19.33/component/trie/domain_set.go) 分别输出精确域名和仅子域名条目，必须保留这一区别。

本次修改：

- 精确域名、包含自身的后缀和仅子域名分别使用字符串索引。大量普通后缀不再逐条编译正则。
- 同一域名同时包含精确项和仅子域名项时，合并为等价的后缀匹配；仅有子域名项时仍不匹配域名自身。
- Fake-IP 域名产物采用同一去重结果并稳定排序，避免重复展开。通配符与正则仍保留原有匹配范围；前缀为 `.` 或 `+.` 且包含通配符的条目按对应的子域名范围编译。
- 真正的正则与关键词索引分块构建。单块过大时继续拆分；每块限制为 4 MiB，最多 16 块，并限制运行时 DFA 缓存。不会通过关闭资源限制接受无限复杂的表达式，也不会丢弃超限条目。
- GeoSite 的真实正则使用同一分块索引。错误会包含具体的规则集或分类名称。

修改只改变索引构建与等价表达，不自动新增分流动作。导入继续遵循先下载、解析，再提交的流程；失败保留原配置。

## 配色

- 未保存有效配色时，默认采用“强国”。首屏初始化脚本与设置读取使用同一默认值；保留已保存的用户选择。
- 配色菜单中的“液态玻璃”去掉“仅 Chromium”副说明。效果实现和兼容处理不变。
