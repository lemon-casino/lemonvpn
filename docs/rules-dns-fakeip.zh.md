# 规则集、DNS 与 Fake-IP 管理

本次实现面向 LemonVPN 0.1.37，共享引擎覆盖 Windows、macOS、Linux。未运行测试、客户端或网络探测；编译检查不能代替实际环境验证。

## 使用入口

- **规则 → 规则集**：新增 URL、导入文件或粘贴内容；支持 YAML、Text、MRS v1，自动识别 domain / ipcidr / classical。可编辑、启停、更新、取消更新、分页搜索内容、查看摘要和引用数量。
- **规则 → 地理数据**：统一管理 GeoSite/GeoIP 来源与更新，搜索分类、查看样例及引用，直接建立路由分流或 DNS 策略。设置页保留状态和跳转。
- **规则 → 路由规则**：普通规则新增“规则集”匹配；下方“分类分流”管理复用资源的出站动作，支持行内拖拽。普通规则优先于分类分流，全局/直连模式仍优先；默认出站最后匹配。
- **规则 → DNS 规则**：请求和响应条件可引用规则集，动作可选择解析池；不适用于该阶段的 IP、进程等条件会被拒绝，不会悄悄忽略。
- **DNS → 解析策略**：按顺序匹配域名、GeoSite、规则集等条件，选择解析池及地址模式。国内外分流向导先展示要建立的策略，用户确认后一次提交；不会升级时自动开启或改写已有规则。
- **DNS → 上游**：管理可复用服务器、主备/竞速解析池及独立引导 DNS。UDP、TCP、DoT、DoH 共用受保护的直连、策略组或链式代理出站。TLS 始终验证证书；不支持跳过验证。
- **DNS → 缓存**：管理实际 DNS 报文缓存、负缓存、热点预取和故障旧值，查看命中/合并查询及上游耗时；可按域名或整体清理。原解析记录索引保留在折叠区。
- **DNS → 查询 / 规则 → 追踪**：共用逐步分析结果，显示版本、资源命中、DNS 策略、缓存来源、实际解析池及响应动作、地址策略和模拟出站。可显示链式路径；离线分析不发请求，实时模式只查 DNS，不探测网站。

## 资源及引用

资源使用稳定 ID，改显示名称不会破坏引用。规则集是匹配范围；路由出站、DNS 解析池和 Fake-IP 地址方式由使用处决定。

新增或编辑后点击“保存并应用”。单项启停、更新及松手排序直接提交；忙碌期间禁止重复提交，失败回读实际状态。并发编辑携带修订，旧草稿不能覆盖新版本。

删除规则集、服务器或解析池时列出引用，可统一替换或明确移除关联规则。删除策略组、链式出站的既有流程同时处理新增的 DNS、分类分流和资源下载引用。不能替换为不适用的对象，例如 DNS 连接不能使用 block。

远程资源支持更新间隔、下载出站、ETag/Last-Modified、自定义请求头和可选预期 SHA256。重定向跨源时移除认证头，拒绝 HTTPS 降级；下载失败、解析失败或摘要不符保留旧内容。准备阶段取消后不提交结果，已经进行的下载按超时结束；进入原子应用阶段后不再接受取消。

MRS 只接受固定内核对应的 v1 domain/ipcidr 数据；classical 支持域名、关键词、正则、GeoSite/GeoIP、CIDR、端口、协议、进程与 AND/OR/NOT 等可转换条件。其余条件明确报出条目位置。不会把完整 Clash 配置当规则集执行，也不会忽略不支持的条目。

## 解析和缓存

DNS 请求依次使用：已有显式请求规则 → 解析策略 → 原默认上游。响应规则仍可接受、拒绝或换池重查，重查有次数与循环限制。

主备池按成员顺序查询；竞速只并发前两个成员，且必须使用相同出站。DoH/DoT 复用经过验证的连接；失效的空闲连接可重建一次。节点和上游域名使用独立引导解析及缓存，避免“解析代理节点又需要经过该节点”的循环。引导端点必须使用 IP。

真实报文缓存保留未知记录和 EDNS；按 TTL 老化，不拉长短 TTL；带 Cookie/ECS 等不能共享的请求不缓存。NXDOMAIN/空应答仅在 SOA 给出有效负缓存期限时缓存。默认容量 4096 项/16 MiB，LRU 淘汰；上限 20000 项/64 MiB。相同在途查询合并；预取限制并发和频率。预取与故障旧值默认关闭，过期兜底不会沿用 AD 信任标记。本实现不宣称自行完成 DNSSEC 验证。

网络变化或恢复、配置版本和解析出口变化会失效相关缓存/传输连接。旧版本在途回答不能写回新缓存。统计来自真实查询；P50/P95 只反映最近 256 个成功样本，不代表经过测量的固定加速比例。

## Fake-IP 范围

地址池、显式排除、映射持久化继续在 DNS → Fake-IP 设置。解析策略中的显式地址方式共享同一分类：排除名单优先，再按首个显式地址策略匹配，最后沿用基础模式；“沿用”不额外生成地址覆盖。全局 redir-host 始终返回真实地址。

只将能无损表达的域名条件投影给内核，保留精确、后缀、关键词及正则语义。IP/进程/端口或无法投影的复杂组合不能指定 Fake-IP 地址方式，会在应用前说明原因。

**高级分类联动需要管理员服务协议 v2。** 旧服务保持原功能；若应用提示服务版本不足，请在 TUN 模式更新服务。本次构建不替换已安装或正在运行的服务。

服务只接收固定类型、大小和摘要受限的域名产物，分块传输，不接收任意配置、路径、URL 或命令。普通分类更新保留映射；模式和地址池变化可能需要清理映射并让设备重新解析。当前固定内核不提供完整映射枚举，页面如实说明，并提供独立于真实 DNS 缓存的映射清理。

Fake-IP 分配需要实际 DNS 进入 TUN；HTTP/SOCKS 系统代理或局域网共享端口不会自动接管设备 DNS。本次不新增公开 DNS 监听。

## 热更新与恢复

引擎使用资源修订、语义摘要及配置 generation。更新先下载/解析，提交阶段串行校验引用和条件，再同步 TUN 设置及摘要、进程条件与 DNS 缓存，确认成功后持久化并发布快照。只有名称或更新时间变化时不重载网络配置。

源文件和资源同时修改时写恢复日志，active 清单记录唯一提交标记，避免同一资源版本下修改源文件被误认作已提交。失败恢复源文件和内核设置；恢复也失败时保留真实错误。后台保留当前及最近资源修订，清理过期孤立资源。

路由变化重新判断活动连接，只退役出站、链路或节点内容受影响的连接。DNS、名称等修改不会无条件断开全部连接。既有 TLS/TCP 流无法无重连迁移节点；这里的热更新指提交后立即使用新配置，不等下一次手动连接。

## 管理接口

为保证跨模块一次提交，实际接口统一为资源文档，而非分别更新数个资源端点：

| 接口 | 用途 |
|---|---|
| `GET/PUT /api/v1/rules/runtime` | 读取/原子提交资源文档；写入携带 revision |
| `POST /api/v1/rules/runtime/import` | URL/文件导入，返回后台 operation |
| `POST /api/v1/rules/runtime/refresh`、`cancel` | 更新和请求取消 |
| `GET /api/v1/rules/runtime/entries`、`references` | 分页内容及引用 |
| `POST /api/v1/rules/runtime/remove` | 替换引用后统一删除 |
| `GET /api/v1/geodata/categories`、`categories/detail` | 分类和样例 |
| `POST /api/v1/dns/trace` | 离线分析/主动 DNS 查询 |
| `GET /api/v1/dns/statistics` | 实际缓存及端点统计 |
| `GET/DELETE /api/v1/dns/wire-cache` | 报文缓存及清理 |
| `POST /api/v1/dns/wire-cache/fakeip/flush` | 独立清理内核映射 |
| `GET /api/v1/runtime/apply` | 当前版本、应用阶段及同步状态 |

能力声明为 `x-rules-runtime` v1、`x-dns-settings` v2。已有 DNS/配置接口保留，旧配置不强制迁移。
