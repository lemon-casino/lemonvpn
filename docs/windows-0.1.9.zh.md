# Windows x64 0.1.9

- 策略组名称支持中文等 Unicode 字母、数字、组合字符，以及原有下划线、句点和连字符。名称仍不能包含空格或配置结构分隔符，避免写入后产生歧义；界面提示同步更新。
- 修复地区筛选显示有节点、保存后的组却为空：前端地区选择生成 `name(regex: '(?i)...')`，旧引擎把正则表达式当作精确名称。现在使用 Rust regex 执行完整匹配，支持地区条件的大小写标志和中文别名。
- 名称、订阅标签均支持精确值、关键字及正则条件。参数之间按 OR 合并，`&&` 按 AND 合并，多条过滤行按 OR 合并；取反及显式空节点选择保持有效。引号内的逗号、`&&` 和括号不会被误拆。
- 无效正则及不完整的筛选语法返回具体校验诊断，不再静默当作普通节点名称。
- 修复中文组名与节点名在 HTTP 路径、组筛选查询参数中的 URL 编码处理，覆盖详情、组配置、成员选择、清除覆盖和按组查询节点；配置中已加引号的中文组名也可正常读取。
- 更新后引擎按新逻辑读取已有组筛选，无需为了地区匹配重新创建原来的组或重新导入订阅。

沿用 0.1.8 的所有策略选择方式、无边框窗口、与版本同行的设置入口及桌面鼠标交互规则。正式发布和 ARM64 继续延后。

本轮仅 TypeScript/Rust 编译及 Windows x64 构建，未执行测试、启动新客户端、安装更新、改写用户当前配置或重启当前服务；运行时效果未在本轮实测。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.9_x64-setup.exe`。
