# Windows 0.1.27：真实流量链路预览

活动卡片与出站中的“链路预览”共用新的拓扑：本机、实际前置／落地节点、访问目标以卡片和曲线虚线连接。保留预览按钮与弹框，出站列表改为紧凑链路摘要，移除占空间的四块示意图。左侧常用顺序调整为状态、活动、订阅、出站。

动画按每秒的链路连接快照计算上传／下载字节增量。首次采样、没有流量、连接结束、数据过期或获取失败时停止，不使用累计字节或虚构目标制造动画。每个有效采样只播放一次有限时长的流动；页面隐藏、卡片不可见或开启减少动态效果时暂停。并发目标优先展示当前流量较高的实际连接。

前置和落地策略组的当前选中节点随连接快照同步更新。连接记录保留建立时的实际节点及前置／落地分界；当自动策略的当前选择与存量连接路径不同时，分别注明，避免把新选择误当成旧连接的路径。后端先按链路过滤连接再截取，并在同一配置快照中返回节点选择。

执行前端类型检查、相关 ESLint／格式检查、Rust workspace 编译检查及 Windows x64 安装包构建。未运行测试、网络探测或实际流量验证，未启动、安装、重启或修改当前运行的软件／服务，未更改用户配置、系统代理或 TUN。正式发布、ARM64 及其他系统构建继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.27_x64-setup.exe`。
