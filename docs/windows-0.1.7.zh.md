# Windows x64 0.1.7

- 桌面侧栏活动小工具取消默认 340px 的固定撑高，默认高度按实际内容收紧，底部版本信息紧跟内容。压缩卡片上下内边距、模块间距和底部信息行。
- 规则、直连、全局共用相同的两行布局：模式选择和全局出站。全局出站行始终显示，在规则、直连模式下置灰；切换模式只改变选中状态与可用状态，不增减行数。
- 删除空的提示占位行。无可用全局出站时，通过出站控件的禁用提示说明原因，不额外撑高小工具。
- 首次进入此版本时清除旧的停靠高度，保留小工具项目、展开和嵌入等设置；之后用户手动拖动设置的高度仍会保存。
- 保留选择模式立即切换、右侧文字不裁切及三个点内的展开/收起与嵌入操作。

仅进行 TypeScript 编译与 Windows x64 构建，未运行测试、启动客户端、安装更新、重启服务或修改使用中的代理和网卡。正式发布和 ARM64 继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.7_x64-setup.exe`。
