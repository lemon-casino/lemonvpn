# Windows x64 0.1.23：简化域名匹配名称与提示

依据选项由“域名后缀”改为“域名及子域名”，由“完整域名”改为“仅此域名”，避免将后缀误解为 .com，或把完整域名误解为包含子域名。

精确匹配提示改为“仅匹配该域名，不含子域名。”，域名及子域名提示改为“匹配该域名及其子域名。”，GeoSite 提示改为“匹配分类内的关联域名。”。同步简化繁体中文和英文文案，列表与新建、编辑表单共用这些提示。

仅调整显示文案和桌面版本号，不改变规则匹配逻辑。构建 Windows x64 安装包，不运行测试、不安装或启动客户端，不修改当前配置、代理、TUN 或服务。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.23_x64-setup.exe`。
