# 局域网共享

入口：设置 → 通用 → 局域网共享。Windows、macOS、Linux 使用同一个共享引擎入口。

## 连接方式

1. 打开“允许局域网连接”，选择网卡与共享端口（默认 `18081`），按需开启用户名和密码认证。
2. 点击“保存并应用”。“共享中”表示代理端口已监听；下方列出可用的网卡 IPv4 地址。
3. 另一台设备连接相同 Wi-Fi 或有线网络，在手动 HTTP 代理中填写该地址和端口。支持 SOCKS5 的应用也可使用同一端口。可以复制完整地址；复制内容不包含认证密码。
4. 保持 LemonVPN 运行，并允许防火墙接收该 TCP 端口。Wi-Fi 客户端隔离会阻止设备相互连接，需要在路由器上关闭。

例如本机地址为 `192.168.1.10`，则其他设备填写服务器 `192.168.1.10`、端口 `18081`；不要填写 `127.0.0.1` 或 `0.0.0.0`。HTTPS 网站通过 HTTP CONNECT 隧道访问。

## 行为与边界

- 默认关闭，单独监听共享端口；不会把本机管理 API 直接开放到局域网。
- 接收私网 IPv4 或本机回环来源，支持 HTTP 转发、HTTPS CONNECT、SOCKS5 CONNECT（TCP）。当前不提供 IPv6 入站、SOCKS5 UDP 转发或透明网关模式。
- 共享连接沿用当前规则、全局/直连模式、策略组及链式代理；连接和流量会计入现有监控。
- HTTP Basic 与 SOCKS5 用户名密码认证可选；共享入站不接受 TUN 内部代理身份，不向目标服务器转发代理认证头。
- 共享入站不允许通过直连访问回环、私网、链路本地等目标，防止从代理转入本机管理接口。直连域名解析后固定已检查的公网地址。
- 关闭共享、修改端口/网卡/认证会关闭原共享连接；本机回环代理、系统代理和 TUN 不需要重启。
- 设置持久化到用户数据目录的 `lan-settings.json`，下次启动恢复。保存采用修订校验和原子写入；端口占用、启动失败或写入失败时保留原设置与原监听。
- 网卡地址每 10 秒及运行状态事件后刷新，也可以点击“重新加载”。网卡枚举只读，不进行联网探测或修改防火墙。
