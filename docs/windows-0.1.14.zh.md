# Windows x64 0.1.14：订阅节点所属组管理

订阅页的节点操作菜单新增“管理所属组”。打开后勾选需要加入的组，取消勾选移出，改选其他组完成更换；支持多组选取、搜索以及移出所有可修改组。原探测、加入组、更换国旗入口保留。只读或未能完整读取的组不允许在此修改。

## 保存行为

- 依据实际生效的所属组初始化勾选，适用于显式选入、订阅匹配、地区正则和嵌套组成员。
- 从自动匹配的组移出时，向该组的筛选添加当前节点的精确排除条件，保留原订阅、地区和其他筛选，不移除其他节点。
- 移除组内最后一个成员时保留有效的空匹配条件，避免删除最后一行 filter 后变成“所有节点”。
- 更换组时在一次保存中处理移出与加入，重新评估嵌套组，使最终所属组与所选结果一致。其他节点的成员关系也会检查，检查失败则不写入。
- 同步移除该节点在被移出组中的默认成员、直接指向它的兜底设置以及 TCP / UDP 固定选择，已建立连接延续原来的路由决定。
- 订阅节点本身保留，订阅源和节点链接不会被删除。筛选使用正确引用的节点名称，支持中文及带引号、反斜线的名称。

后端新增 LemonVPN 扩展 `PUT /api/v1/nodes/{node_id}/groups`，通过 `x-node-membership` 能力控制入口。请求携带原所属组和配置代次；配置或订阅变化、外部文件修改时拒绝旧编辑。涉及多个配置源时先完整校验，再写盘；任一写入失败会尝试恢复已经写入的文件，保持原生效快照，外部再次修改的文件不会被强行覆盖。成功后一次发布新生效代次并刷新节点、策略和配置数据。

## 构建范围

仅进行 TypeScript 类型编译、Rust 编译及 Windows x64 安装包构建，未运行测试、客户端或新内核，没有切换系统代理、TUN 或更新正在运行的服务。本轮未进行运行验收。正式发布及 ARM64 继续延后。
