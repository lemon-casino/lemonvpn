# Windows x64 0.1.18：侧栏与活动页出站稳定布局

左侧活动小工具与活动页的模式显示规则同步：仅选择全局模式时显示全局出站名称和选择器。规则、直连模式下卸载该行控件，移除键盘焦点入口，并关闭原选择器可能打开的菜单。

模式行和全局出站行使用固定高度，非全局模式下保留第二行的空间。因此三种模式切换时小工具高度、底部版本行及停靠位置保持一致。侧栏中单独放置的全局出站模块也沿用相同的显示规则与固定行高。

保持侧栏选择模式、选择全局出站后直接生效的交互，不增加“应用”按钮；活动页保留 0.1.17 合并后的单次应用。

活动页同样保留全局出站的宽度占位，非全局模式下将这一组控件设为不可见、不可操作。选择器按最宽的出站名称预留宽度，避免模式按钮与“应用”被整组控件宽度的变化推移；模式变更时重建选择器，关闭旧的弹出菜单。

执行修改文件的静态检查、TypeScript 类型编译和 Windows x64 安装包构建，未运行测试、启动软件或内核、修改当前配置，也未替换使用中的客户端或服务。本轮没有运行验收。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.18_x64-setup.exe`。正式发布、Windows ARM64 和其他平台构建继续延后。
