# Windows x64 0.1.11

## 策略组解除固定

- 修复解除固定返回 HTTP 204、前端要求 JSON 而弹出“后端响应没有 JSON 内容”的问题。成功响应改为 HTTP 200，包含协议范围、选择版本、解除后的 TCP/UDP 选择，以及未中断现有连接的标记。
- 前端兼容旧引擎的成功 204 响应：重新读取组详情，恢复当前选择状态；读取失败仍会报告实际错误。
- 手动固定响应补齐选择版本和连接中断标记；组列表按接口约定返回 TCP/UDP 成员 ID，避免列表与详情字段不一致造成持续刷新。

## 连接新建规则的依据

- 保留完整域名、域名后缀、域名关键字、目标 IP、来源 IP。
- 根据连接实际提供的数据，增加目标端口、来源端口、TCP/UDP 协议，以及域名＋目标端口、目标 IP＋端口、来源 IP＋端口、协议＋目标端口。
- 流程记录的新建规则入口共用上述依据；缺少对应数据时不显示该项。进程名依据仅在后端连接记录提供可写入的进程名时显示；本轮未增加原生进程归属采集。
- 共享引擎补入 `dip`/`sip`、域名关键字、`dport`/`sport`、`l4proto` 与 AND/OR 条件的解析及匹配。支持端口列表、端口范围、IPv4/IPv6 主机与 CIDR；不支持的条件继续在写入校验时拒绝。
- HTTP、SOCKS TCP/UDP 和内置 TUN TCP 路由传入可用的来源地址、来源端口、目标端口与协议。条件仅按路由入口能观察到的数据匹配；代理转发后的来源不等于原始应用来源。
- 路由模拟使用请求中的协议、来源/目标 IP 及端口，避免新增条件被忽略。

本轮仅进行 TypeScript/Rust 编译和 Windows x64 安装包构建，未运行测试、启动新客户端、切换当前代理/TUN、修改用户配置、安装更新或重启服务。运行时效果未在本轮实测。正式发布与 ARM64 继续延后。

安装包：`app/src-tauri/target/release/bundle/nsis/LemonVPN_0.1.11_x64-setup.exe`。
