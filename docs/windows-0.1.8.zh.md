# Windows x64 0.1.8

## 桌面窗口和交互

- Windows 主窗口取消系统标题栏和装饰，最小化、最大化/还原、关闭按钮放在顶部主题操作右侧。保留顶部空白处拖动、双击最大化及原有关闭后驻留托盘的行为。启动等待和登录界面也提供窗口按钮。
- 桌面页面禁用浏览器右键菜单和普通内容的鼠标选中。输入框、文本框及配置编辑器保留选择、编辑和键盘复制粘贴；已有复制按钮仍可使用。网页宿主保持原有交互。
- 设置改为版本信息右侧同一行的齿轮入口，去掉侧栏底部独立的设置行；小工具收起、隐藏或取消嵌入后，版本信息与设置入口仍可访问。

## 策略组

新建组原先默认写入 `min_moving_avg`，引擎只接受 `selector`、`fixed(n)`、`random`，因而校验失败。本版保留所有选择方式，并实现对应的数据路径行为：

| 选择方式 | 行为 |
|---|---|
| 平均最快 | 对可用节点的延迟做指数移动平均，选择均值最低者 |
| 综合评分 | 结合近期成功率、探测延迟、连接耗时和延迟波动选择节点 |
| 按顺序备用 | 保持当前可用成员；不可用时按成员顺序为后续连接选择备用 |
| 负载均衡 | 每个新连接/UDP 会话按顺序轮换可用成员，TCP/UDP 分别计数 |
| 手动选择 | 使用用户选择或默认成员 |
| 随机、固定 | 保留随机选择及 `fixed(n)`，固定入口默认第一个节点 |

- 支持 `select`、`selector`、`urltest`、`min_moving_avg`、`min_avg10`、`min_last_delay`、`score`、`fallback`、`roundrobin`、`round_robin`、`loadbalance`、`balance` 等对应写法。
- 自动策略使用成员健康检查及真实 TCP/UDP 连接反馈；健康检查由安装后的引擎管理，最多两个同时进行，并优先处理未检查或最久未检查的成员。更换节点地址或凭据后不沿用旧节点的健康记录。
- 读取组状态及路由预览不会推动轮换位置。已建立的连接保持其原出站；手动覆盖选择仍优先生效。
- 未写过滤条件时表示全部节点，与新建组界面一致；显式空节点选择仍保持为空。
- 校验拒绝时保留并显示具体诊断和行号，不再只有错误数量。现有文件与已有策略不会因打开编辑器而被自动改写。

本轮只做 TypeScript/Rust 编译和 Windows x64 构建，未运行测试、启动新客户端、安装更新、重启服务或切换当前代理与网卡。正式发布及 ARM64 继续延后；运行时效果未在本轮实测。
